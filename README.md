# MD5 查重去重工具

面向 Windows 的**绿色版** MD5 查重 / 去重小工具。扫描目录（或单个文件）算出每个文件的 MD5，
把内容完全相同的文件挑出来，并把结果存档成可叠加、可导出、可反复比对的「MD5 列表」。

单文件 exe，无需安装 Go / .NET，配置与数据都在程序同级的 `data` 目录里，拷走即完成迁移。

![目录扫描](docs/screenshot-scan.png)

---

## 功能特性

- **多目标扫描**：一次可扫描多个目录，也可以只扫单个文件，结果合并为同一份；文件夹 / 文件直接拖进窗口即可加入。
- **增量复用**：第二次扫描同一目录时，未变化的文件直接复用上次算好的 MD5（结果里的「增量复用」就是跳过的数量），大目录重复扫描非常快。
- **重复组视图**：一眼看到哪几个文件互为副本、各自多大、一共能省多少空间。
- **文件查重**：拿一个或多个「基准列表」去比对任意目录 / 文件，只对待查对象算 MD5，用于「这批新素材和已有库里有没有重复」这类场景。
- **结果可存档**：扫描与查重的结果都能一键存档为列表 —— 新建一个，或叠加到已有列表上。
- **列表自动去重**：新建、叠加、导入、查重存档四条路径都会自动按 MD5 合并，列表里不会留重复条目。
- **可回溯的删除**：查重命中项可批量移入 **系统回收站**（不是直接删除），并写入日志，事后可查。
- **导入 / 导出**：列表支持 JSON（可再次导入）、CSV（Excel 可读）、纯文本三种格式。
- **并发可调**：默认自动按 CPU 核数，也可以手动指定线程数。
- **纯绿色**：无边框自绘界面，Material Design 3 深色主题，所有数据落在 `data` 目录。

## 系统要求

| 项目 | 要求 |
| --- | --- |
| 系统 | Windows 10 1809 及以上 / Windows 11（x64） |
| 运行时 | Microsoft Edge WebView2 Runtime（Windows 11 自带；Windows 10 一般也已随 Edge 安装，缺失时按提示装一次即可） |

> 目前只发布 Windows x64 版本。源码本身可跨平台编译，但界面上的窗口按钮等交互是按 Windows 习惯做的。

## 下载与安装

**方式一：直接下载（推荐）**

到仓库的 **Releases** 页面下载 `MD5Deduper-vX.Y.Z-windows-x64.exe`，放到任意目录双击运行即可，无需安装。

**方式二：用 GitHub Actions 手动构建**

仓库内置了手动构建流程（`.github/workflows/manual-build.yml`），不需要本地环境：

1. 打开仓库 **Actions** 页面 → 左侧选 **Manual Build** → 右上角 **Run workflow**；
2. 按需填写参数（版本号、Go 版本、Wails 版本，是否生成 NSIS 安装包，是否创建 Release）；
3. 跑完后在本次运行的 **Artifacts** 里下载 `MD5Deduper-<版本>-windows-x64`，解压得到 exe。

也可以用命令行触发：

```bash
gh workflow run manual-build.yml -f version=1.0.1
```

**方式三：本地从源码构建**

见 [DEVELOP.md](DEVELOP.md)。

## 快速上手

1. **扫描一遍你的目录** —— 打开「目录扫描」，把要整理的文件夹拖进窗口，点「开始扫描」。
2. **看结果** —— 「重复」页签里就是所有内容重复的文件；「可释放空间」告诉你删掉多余的副本能省多少。
3. **处理重复** —— 想删就直接删；想留证据就先存档成列表，或者去「文件查重」把候选文件和已有列表比对后再决定。

## 界面说明

界面分三块：

- **左侧导航**：四个页面（扫描 / 查重 / 列表 / 设置），导航栏直通窗口顶部。
- **顶部栏**：左侧是程序 Logo，右侧是最小化 / 最大化 / 关闭。整条栏都可以拖动窗口。
- **底部功能区**：当前页面最常用的按钮都集中在这里，左边显示当前状态（如「上次扫描：… · 可释放 …」）。
  页面里的次级按钮则放在卡片内部。

**拖放**：把文件夹或文件拖到窗口任意位置即可加入当前页面的目标列表（扫描页加入扫描目标，查重页加入待查对象），
拖放时窗口会给出提示。

## 功能详解

### 目录扫描

![扫描结果](docs/screenshot-result.png)

1. **添加扫描目标**
   - 直接把文件夹 / 文件拖进窗口；
   - 或在输入框里粘贴路径后回车；
   - 或点输入框右侧的「选目录」「选文件」按钮。
   - 目标会以标签形式列出，点标签上的 ✕ 单独移除，输入框旁的「清空」按钮一次清空全部。
2. **填存档信息（可选）**：可以给本次扫描结果起个「列表名」和「备注」；备注默认填当前日期时间到秒。
   也可以直接勾选叠加到某个已有列表。不填名称时会按目标自动生成。
3. **开始扫描**：点击后先枚举文件，再计算 MD5，进度条显示阶段、已完成数、速度与预计耗时。可随时「取消扫描」。
4. **看结果**：
   - 顶部统计卡：文件总数、唯一 MD5、重复组、重复文件、可释放空间、总大小、增量复用、耗时；
   - 页签：**全部 / 重复 / 错误**，可搜索路径或 MD5，列表可按列排序、分页；
   - 扫描结果会按设置自动存档为列表（卡片标题右侧会显示已存档的列表名）。
5. **底部按钮**：`[重置] [清空结果] [开始扫描]`。「重置」会清空扫描目标、结果与存档设置。

> 扫描与查重一律递归子目录、跳过隐藏文件，不限制文件大小。

### 文件查重

![文件查重](docs/screenshot-check.png)

用于回答「这些新文件里，有哪些已经在我的库里了？」

1. **选基准列表**：可以多选。列表内容就是之前扫描或导入的 MD5 库。
2. **添加待查对象**：拖入文件 / 文件夹，或点「选目录」「选文件」按钮。
3. **开始查重**：只对待查对象计算 MD5，再和基准列表比对。
4. **结果操作**：
   - 按「仅重复 / 全部」筛选，搜索路径或 MD5，分页浏览；
   - **全选命中** 一次性勾选所有重复项；
   - **移入回收站** 把勾选的文件批量移到系统回收站（会先确认并显示可释放空间）；
   - **存档为列表** 把结果存成列表，可选择「新建列表」或「叠加到已有列表」，并可只存档命中的重复文件。
5. **底部按钮**：`[重置] [清空待查] [开始查重]`。

### 列表管理

![列表管理](docs/screenshot-lists.png)

列表 = 一份 MD5 库（`MD5 / 大小 / 文件名`）。

- **左侧**：搜索框直接在最上方，下面就是列表；单击选中，**Ctrl 点击多选**，**Shift 点击范围选**。
- **右键**：`复制` / `叠加选中列表` / `删除`。
- **右侧详情**：可修改列表名称与备注并保存；顶部标签显示条目数、总大小、更新时间、层数。
- **条目区**：表头为 MD5 / 大小 / 文件名，可按 MD5 或大小排序；点击一行打开条目详情（列出该 MD5 对应的所有文件名，可定位或复制路径）。
- **底部按钮**：`[导入] [导出] | [定位] [复制] [删除]`。
  - **导入**：读取之前导出的 JSON 列表文件，导入后自动去重；
  - **导出**：JSON / CSV / 纯文本；
  - **定位**：在资源管理器中定位列表的 JSON 文件；
  - **复制**：把列表另存为一个副本；
  - **删除**：删除当前列表；若左侧有多选，则批量删除选中的列表。

**关于去重**：不需要手动去重。新建列表、叠加、导入、查重存档时都会自动按 MD5 合并，
同一 MD5 的多个文件路径会合并到同一条记录里。

### 设置

- **并发数**：默认「自动」（= CPU 核数），也可手动指定线程数。
- **每页条数**：列表与结果表格的分页大小。
- **数据**：显示数据目录与程序目录的完整路径。
- **底部按钮**：`[保存设置] [打开数据目录] [回收站日志] [恢复默认值] [重新载入]`。

## 数据存放与备份

所有数据都在**程序所在目录**的 `data` 文件夹下（若程序目录不可写，会退回到当前工作目录）：

```
data/
├── config.json          # 设置
├── lists/<id>.json      # 每个列表一个文件（含条目）
├── export/              # 导出的 JSON / CSV / TXT
└── trash-log.jsonl      # 移入回收站的操作日志
```

- **备份 / 迁移**：把整个程序目录（含 `data`）复制走即可，换机器直接能用。
- **重装**：删掉 exe 不影响数据；删掉 `data` 相当于恢复出厂设置。

## 常见问题

**Q：双击没反应 / 提示缺少 WebView2？**
安装一次 [Microsoft Edge WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/)（常青版），再启动即可。

**Q：扫描很慢怎么办？**
先在「设置」里确认并发数；如果是机械硬盘或网络盘，瓶颈通常在 IO 而不是 CPU，把并发调低有时反而更快。
同一个目录第二次扫描会走「增量复用」，未变化的文件会被跳过。

**Q：扫描时我把窗口关了，任务会怎样？**
任务进行中关闭程序会先弹出确认框；确认退出后任务会被中断。

**Q：删除的文件去哪了？**
「移入回收站」走的是系统回收站，可以正常还原；操作记录写在 `data/trash-log.jsonl`，也可在设置页点「回收站日志」查看。

**Q：列表里为什么没有「来源路径」？**
列表只记录 `MD5 / 大小 / 文件名` 三项，来源目录不再保留，避免把本机路径带进库里。

**Q：能不能只扫单个文件？**
可以。扫描目标和待查对象都接受单个文件。
